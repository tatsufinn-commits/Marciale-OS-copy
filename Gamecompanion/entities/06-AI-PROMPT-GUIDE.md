# AI ART PROMPT GUIDE — PIXELLAB AI + PIXELIORAMA
## Phase 7 Supplement | Ready-to-Paste Prompts
**Tool Target:** Pixellab AI (for generation) / Pixellab / Pixellora / etc.
**Style Guide:** Pixel art, game-ready sprites, transparent background

---

# HOW TO USE THIS GUIDE

Each entry provides:
1. **Direct prompt** — paste verbatim into Pixellab AI or a pixel art generator
2. **Suggested adjustments** — refinement notes after initial generation
3. **Post-processing notes** — what to clean up in Pixellab (resize, palette swap, frame duplication)

**Recommended Workflow:**
1. Paste prompt → generate base sprite
2. Adjust in Pixellab: clean up stray pixels, ensure consistent line width (1-2px)
3. Resize to exact game canvas size using nearest-neighbor (no anti-aliasing)
4. Export as PNG with transparent background
5. Name per convention: `[entity]_[variant]_[size].png`

# PART 6: TROUBLESHOOTING GUIDE

| Problem | Likely Cause | Fix |
|---------|-------------|-----|
| Colors wrong | Pixellab AI interpreted prompt differently | Adjust in post: use Pixellab's color replacement tool with hex values from this guide |
| Too many colors | AI added shading gradients | Reduce palette manually to 8-10 colors per sprite |
| Anatomy issues on characters | Body part proportions are off | Fix by erasing and redrawing specific sections in Pixellab's pixel editor |
| Not pixel art style | AI generated a smooth rendered image | Use Pixellab's "pixelize" filter, then clean up with nearest-neighbor resize to target dimensions |
| Background not transparent | AI added a background | Use Pixellab's magic wand + delete, or a dedicated background removal tool before importing |
| Species features missing (ears, tail) | AI ignored that detail | Manually add pointed ears / tail in Pixellab — these are critical identifiers |
| Too small for detail | Target canvas is very small | Generate at 2x size (64×96 for a 32×48 target) then nearest-neighbor downsample |
