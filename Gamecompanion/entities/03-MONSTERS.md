# SECTION C: SPRITE SHEET LAYOUT RECOMMENDATIONS

For each monster, create a sprite sheet at the following format:

```
[Idle 1] [Idle 2] | [Walk 1] [Walk 2] [Walk 3] [Walk 4] | [Attack 1] [Attack 2] [Attack 3] | [Hit 1] [Hit 2] | [Death 1] [Death 2] [Death 3] [Death 4]
```

**Recommended sheet canvas size per monster:**
- Small (32×32): 256×64px sheet
- Medium (48×48): 384×96px sheet  
- Large (64×64): 512×128px sheet
- Boss (72×64+): 576×160px sheet
