# II. THE 3 CORE PILLARS OF THE ECOSYSTEM

---

### 🏛️ PILLAR I: TheHUB Personal Command Center (`hub/` / `TheHUB 1.5.5.2.3 a v/`)
* **Core Technology:** Lightweight Vanilla JavaScript, HTML5, CSS3, Python Threading Server (`server.py` on `127.0.0.1:8000`).
* **Active Subsystems:**
  1. **Today Dashboard:** Unified situational view with daily task queues, biometric energy levels, and the glowing **Mapúa Exam Countdown Card**.
  2. **Kanban & Pomodoro "LOCK IN":** Visual drag-and-drop task columns linked to focused 25/50-minute work blocks.
  3. **Biometric Pharmacokinetic Engine (`04-tracker.js`):** Calculates real-time caffeine elimination curves ($5.7\text{ hr}$ half-life) and warns against sleep disruption.
  4. **Client-Side Encrypted Vault (`07-vault.js`):** Government-grade AES-GCM-256 zero-knowledge encryption with PBKDF2 key derivation.
  5. **ChessLab AI Core (`15-chess.js`):** Grandmaster calculation core with Stockfish 16 WASM, Maia ONNX neural move evaluation, and sub-5ms Positional Safety Heatmap overlays.
  6. **Spatial Sensing & RuView (`17-19-presence.js`):** Local WebSocket sensing proxy with automatic vault lock and focus pause on user absence.

---

### ⚔️ PILLAR II: The Momentum Companion RPG (`companion/` / `Gamecompanion/`)
* **Core Technology:** HTML5 Canvas 2D, Pure ES Modules, Vite Bundler, IndexedDB Persistence (`idb`).
* **Active Subsystems:**
  1. **The Game Loop (`GameLoop.js`):** 60 FPS active combat loop with automatic 5 FPS background throttling to save laptop battery.
  2. **Combat & Loot Engines (`CombatEngine.js`, `LootEngine.js`):** Auto-attacks, range detection, 75% physical armor cap, boss phase-two transitions, and stage chest loot tables.
  3. **TheHUBBridge Protocol (`TheHUBBridge.js`):** The bidirectional `postMessage` bridge that catches `hub.activity` events from TheHUB and converts real-world task completions into in-game **Gold, Experience, and floating celebration particles**!

---

### 🎓 PILLAR III: TAMA Academic Architecture Engine (`TAMAintegration/`)
* **Core Technology:** 7-Cluster Knowledge Vault Spine, Socratic Testing CLI, Mobile Anki Exporter, TheHUB Integration Plugin.
* **Active Subsystems:**
  1. **The 7-Cluster Knowledge Vault (`vault/`):** 180+ reference files organized across Building Laws, Design Studio (AD1–AD10), Building Tech (BT1–BT5), Building Utilities (BU1–BU4), Structures (STRUC1–STRUC4), History/Theory (HOA/TOA), and Planning/Ecology.
  2. **Socratic Exam Generator & Reviewers (`reviewers/`):** Departmental Mock Exam Sets 01–05, 50-Item Comprehensive ALE Exit Simulation, and 4 Active Recall Decks.
  3. **CLI Math & Study Suite:** `study.js` (5-mode terminal flashcards), `solve.js` (AMBF, RCD beam, and acoustics calculator), `grade-exam.js` (automated exam grader), and `export-anki.js` (Anki mobile exporter).
  4. **TheHUB Plugin Bridge (`TAMAplugin/`):** Connects TAMA directly into TheHUB, activating the `mapua_architect` Socratic Brain Profile for Marciale AI!
