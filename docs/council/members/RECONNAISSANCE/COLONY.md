## G. WANTED EXTRACT — BE DIRECT (Kitchen 2026-08-13)

Colony is not a search engine. It is a **refinery**. For every source, fill the **Wanted** boxes for that platform. Empty boxes = incomplete audit.

### G0. Universal (every source)

| Wanted | Meaning |
|---|---|
| **Claim** | What the source *says* it does (quote) |
| **Proof** | What you *saw* (README, code path, timestamp, UI) `[OBSERVED]` |
| **Upgrade verb** | Add / replace-sandbox / teach-TAMA / reject-as-core |
| **Body** | Marciale-OS · TAMAKEE · both · neither |
| **Folder pin** | Exact existing path that would change *if* approved |
| **Pattern not payload** | Tokens, protocol, UX move, formula — **not** stolen assets |
| **Cost** | New deps? Cloud? Law I rewrite? Law III hardware? |
| **Keep score** | KEEP as upgrade candidate / DEFER / REJECT-as-core |

### G1. GitHub (and any git host)

**WANT to find and extract:**

1. **Identity:** `README` purpose in 2 lines; stars/last commit only as hygiene, not worship.  
2. **License:** `LICENSE` / `package.json` `license`. GPL/AGPL/SSPL = copyleft flag.  
3. **Shape:** top-level tree — is it Vanilla / Vite / React / Python / plugin?  
4. **The one trick:** the *smallest* mechanism we would steal as a *pattern* (e.g. hook, palette, token file, sim mode). Cite path: `src/...`.  
5. **Anti-trick:** what would smash TheHUB if merged raw (framework, cloud API key, electron).  
6. **Folder pin examples:** `TheHUB 1.5.5.2.3 a v/modules/08-assistant.js`, `Gamecompanion/files/src/…`, `tools/`, `docs/web/…`, `TAMAKEE/vault/…`  
7. **Law II verdict:** iframe/sandbox vs never-touch-core.

### G2. YouTube

**WANT:**

1. **Timestamped claims** (`MM:SS` + quote) — not “the video is cool.”  
2. **Technique named:** algorithm, UI move, study method, git ritual, design rule.  
3. **Rebuild locally?** Yes as SIM / notes / token — **no** rehosting the video.  
4. **TAMAKEE hook:** exam tactic, drawing method, code-of-law mnemonic → which `vault/` series.  
5. **Marciale hook:** focus, habit, companion loop, ChessLab, AI prompt — which module.  
6. **Creator ToS:** no transcript dump as if we own it; short quotes + link.

### G3. Instagram / Facebook / TikTok / Reels

**WANT:**

1. **Visual system:** color, type, grid, motion — map to `DESIGN.md` tokens (`#0b0c10`, gold, hairline).  
2. **Interaction:** one gesture/flow we could mock in TheHUB **without** their assets.  
3. **Caption claim** vs **what the pixels show**.  
4. **No image hoard.** Describe; do not rip the Reel into `TheHUB/sounds`.  
5. **Upgrade:** token tweak / sandbox tab — never “redesign the house in their aesthetic.”

### G4. Google (search, Docs, Scholar, official docs)

**WANT:**

1. **Primary > blog.** Prefer spec, man page, RFC, NIST, MDN, repo.  
2. **The sentence that changes our work** — quote + URL.  
3. **Contradiction** with `AI_RULES` / PATH / TAMAKEE law tables — flag it.  
4. **Scholar:** method + sample limits; no fake “n=7 therefore law.”  
5. **Maps to:** named commandment, law, or vault file.

### G5. What we do *not* want (failed extract)

- “Interesting, we should look into this later” with no folder pin.  
- Seven decorative links to hit Patent theater.  
- “Rewrite TheHUB in Next.js because the video used it.”  
- Dropping a Commander URL because it was ugly or blocked.  
- Tasking NTG from the audit footer.
